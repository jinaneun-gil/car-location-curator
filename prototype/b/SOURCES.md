# 콘텐츠 출처와 확인 상태

`content.js`의 이야기(s1~s13)에 쓴 사실과 그 출처다. 출처에서 확인한 내용만 문장으로 썼고, 확인하지 못한 내용은 뺐다.
홍보(a1~a8)의 상호, 쿠폰, 문구는 **전부 가상**이다.

- 확인 방법: 웹 검색 결과의 기사와 자료 원문 문장으로 확인 (2026-11-10). 공식 문화유산 DB 원문은 이 작업 환경에서 열리지 않아 직접 보지 못했다.
- 제출 전에 **⚠ 표시 항목**은 공식 자료로 한 번 더 확인하면 좋다.
- 좌표는 장소 근처를 어림한 값이다. 경로와의 거리는 30~200m이고, 재생 시점에는 문제가 없다. 실제 위치와 크게 다르면 지도에서 보고 고친다.

## 홍보 콘텐츠 원칙

- 상호, 할인, 행사는 모두 가상이다. 실재하는 가게와 이름이 겹치면 바꾼다.
- 모든 홍보 문구는 "광고입니다."로 시작한다.
- 주류 광고는 넣지 않았다. 넣으려면 음주운전 경고 문구가 필요하다.
- 분류(`category`)에 `stay`(숙소)와 `shop`(편의점)을 새로 썼다. 차량 정차 화면의 관심사 목록에도 넣었다.

## 운전 안전 표현 점검

- "오른쪽을 보세요", "창밖을 보면"처럼 시선을 끄는 표현을 쓰지 않았다.
- 걷기를 권하는 문장은 "차를 세운 뒤에"를 붙였다.
