# 화면 시안 (B 담당)

웹 프로토타입의 실제 화면을 상황별로 캡처한 시안이다. 기획서 "7. 참고자료"의 화면 시안으로 첨부한다.
모든 시안은 차량 신호가 시뮬레이션인 프로토타입 화면이다. 화면 위쪽에도 그 문구가 들어 있다.

다시 캡처하려면 저장소 루트에서 아래를 실행한다 (Playwright 필요, 약 1분).

```bash
npm i --no-save playwright && npx playwright install chromium && node design/capture.js
```

|---|---|---|

| `car-02-driving-ad.png` | 주행 중 광고 재생 | 광고는 노란 "광고" 배지와 색으로 이야기와 구분한다. 음성도 "광고입니다."로 시작한다 |

## 디자인 원칙 (공식 가이드 기준, `05_폰vs차량_제약정리.md` 참고)

- **1~2초 안에 파악**: 주행 중 앱 창에는 상태 배지, 제목, 큰 버튼만 둔다. 제목 34px, 버튼 높이 76px 이상.
- **움직이는 요소 최소화**: 진행 막대는 문장 단위로만 바뀌고 계속 움직이는 애니메이션은 없다.
- **음성이 우선, 길 안내가 최우선**: 내비 안내 중에는 앱 창도 "내비 안내" 상태로 바뀐다.
- **광고 구분**: 색(노랑), 배지, 음성 첫마디 세 가지로 광고임을 알린다.
- **정차 시에만 상세**: 긴 설명, 쿠폰, 관심사, 동의 화면은 기어 P에서만 보인다. 주행으로 바뀌면 QR 창도 닫힌다.
- **시선 유도 금지**: "오른쪽을 보세요" 같은 문구를 쓰지 않는다.
- **색 체계**: 이야기 초록 `#4cc2a4`, 광고 노랑 `#f2b04c`, 내비 파랑 `#6aa9ff`. 어두운 배경에서 대비를 높였다.
