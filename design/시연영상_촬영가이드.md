# 시연 영상 촬영 가이드 (B 담당)

웹 프로토타입의 **시연 모드**로 녹화한다. 시연 모드는 정해진 순서대로 버튼을 대신 눌러 주므로, 같은 장면을 몇 번이고 다시 찍을 수 있다.
어떤 이야기와 광고가 나올지는 실제 판단 엔진이 그때그때 고른다. 그래서 찍을 때마다 순서가 조금씩 다를 수 있다.

## 1. 준비 (5분)

1. **PC의 Chrome**을 쓴다. 한국어 음성이 있어야 한다.
   - Windows: 설정 → 시간 및 언어 → 음성 → "음성 추가"에서 한국어 설치. Chrome의 "Google 한국의" 음성은 인터넷이 연결되어 있으면 자동으로 쓰인다.
   - 소리가 안 나면 다른 탭에서 `prototype/index.html`을 열고 "주행 시작"을 눌러 먼저 확인한다.
2. **게스트 창**으로 연다 (Chrome 오른쪽 위 프로필 → 게스트). 계정 이름, 프로필 사진, 북마크가 영상에 나오지 않게 하기 위해서다. **공모전 규정상 실명·계정 정보가 드러나면 안 된다.**
3. 화면 녹화 도구
   - Windows: `Win + Alt + R` (Xbox Game Bar). 앱 소리까지 함께 녹화된다.
   - Mac: OBS Studio에서 "화면 캡처 + 앱 오디오"로 녹화한다. QuickTime은 시스템 소리를 녹음하지 못한다.
4. 창 크기는 1920×1080 전체 화면(F11)이 가장 보기 좋다.

## 2. 녹화

1. 파일 탐색기에서 `prototype/index.html`을 Chrome으로 연다.
2. 주소 끝에 `?demo`를 붙이고 Enter를 누른다. 예: `file:///C:/.../prototype/index.html?demo`
3. F11로 전체 화면을 켜고 녹화를 시작한다.
4. **"시연 시작"** 버튼을 누른다. 음성 재생에는 클릭이 필요해서 이 버튼 하나만 직접 누른다.
5. 마지막 안내 카드("지도 데이터 © OpenStreetMap 기여자")가 나오면 3초 뒤 녹화를 끝낸다.

## 3. 자동으로 진행되는 장면 (전체 약 5분)

시간은 헤드리스 브라우저 시험 기준이라 실제 녹화 때는 조금 다를 수 있다. 화면 위쪽 파란 띠가 지금 어떤 장면인지 알려 준다.

| 대략 시간 | 장면 | 보여 줄 핵심 |
|---|---|---|
| 0:00 | 시작 카드 | "차량 신호는 시뮬레이션" 안내 |
| 0:05 | **상인 광고 등록** | 폰에서 상호, 위치, 노출 범위, 기간, 시간대, 쿠폰을 입력. 미리보기 문장으로 노출 조건 설명 후 게시 |
| 0:35 | 주행 시작 60km/h | 지나는 장소 이야기가 음성으로 나오고, 화면에는 제목과 큰 버튼만 |
| 0:30 | 내비 회전 안내 (일주서로 진입) | 이야기가 멈추고 내비 음성이 먼저 나온 뒤, 멈춘 문장부터 다시 |
| 1:10 | **방금 등록한 광고** → "가 볼래" | "광고입니다."로 시작, 음성 명령으로 경유지 추가, 지도에 핀 |
| 0:40 | 정체 구간 20km/h | 같은 구간에서 긴 이야기로 바뀜 ("길게 듣기") |
| 2:05 | 정체 해소 60km/h | 다시 짧은 이야기 |
| 3:20 | 회전 안내 두 번 | 곽지 진입 |
| 4:00 | 도착, 기어 P | 정차 화면: 오늘 지나온 곳 |
| 4:03 | 쿠폰 QR | 실제로 읽히는 QR |
| 4:07 | 휴대폰으로 스캔 | 폰 앱 "내 쿠폰"에 저장 |
| 4:40 | 매장에서 쿠폰 사용 | 쿠폰이 사용 완료로 바뀜 |
| 4:45 | **상인 성과 화면** | 음성 노출 → 경유지 추가 → 쿠폰 저장 숫자가 올라가 있음 |
| 4:12 | 끝 카드 | 시뮬레이션 안내, 가상 상호 안내, OpenStreetMap 출처 |

화면 아래 자막은 영상용이다(차량 화면에는 나오지 않는다). "가 볼래"는 시연 모드가 대신 입력하며, 자막에 "음성 명령(시연)"으로 표시된다.

## 4. 편집할 때

- 3분 안팎으로 줄이려면 **정체 구간 중간**(긴 이야기 뒷부분)과 **회전 안내 사이의 이야기 몇 개**를 자르면 된다. 시작 카드, 내비 우선 장면, "가 볼래", 도착·QR, 끝 카드는 남긴다.
- 끝 카드의 **"지도 데이터 © OpenStreetMap 기여자"는 꼭 남긴다** (README 규칙).
- 배경 음악을 넣으면 음성이 묻히므로 넣지 않거나 아주 작게 넣는다.

## 5. 직접 조작해서 찍고 싶을 때

`?demo` 없이 열면 오른쪽 "차량 신호 조작" 패널로 직접 조작한다.

- `?caption`만 붙이면 자막만 켜진다.
- "말하기" 버튼으로 실제 음성 명령도 쓸 수 있다. Chrome이 마이크 권한을 물으면 허용한다. "가 볼래", "다음", "그만"을 알아듣는다.
- "내비 안내 지금 발생" 버튼으로 아무 때나 내비 끼어들기를 보여 줄 수 있다.

## 6. 숏폼 (선택, 30초~1분 세로)

- 창을 세로로 좁히면(폭 900px 이하) 차량 화면이 세로 배치로 바뀐다.
- 추천 구성: 불편한 순간(운전 중 궁금해도 검색 못 함) → "가 볼래"로 경유지 추가 → 도착 후 쿠폰 QR.
- 해시태그 `#HMG차량용앱개발공모전`은 반드시 넣는다.

## 녹화 전 점검표

- [ ] 게스트 창이라 계정·실명이 안 보인다
- [ ] 소리가 녹음된다 (10초 시험 녹화로 확인)
- [ ] 시작 카드와 끝 카드에 "시뮬레이션" 문구가 보인다
- [ ] 끝 카드에 OpenStreetMap 출처가 보인다
- [ ] 바탕화면 알림(메신저 등)을 꺼 두었다
